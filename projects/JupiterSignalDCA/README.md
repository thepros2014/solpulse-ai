# JupiterSignalDCA — NMS-Driven Autonomous DCA Agent

## Overview
JupiterSignalDCA is a creative autonomous trading agent built for the Superteam Earn 'Not Your Regular Bounty'. It uniquely combines **SolPulse AI Narrative Momentum Scores (NMS)** with the **Jupiter Developer Platform APIs** to execute a Signal-Weighted DCA strategy.

Instead of dollar-cost averaging blindly, this agent uses SolPulse's AI-driven NMS analysis of Github velocity, on-chain metrics, and social sentiment to dynamically route capital to the tokens driving the hottest narratives on Solana.

## How It Works
1. **Reads Signals:** Parses `signals.json` generated by SolPulse AI to extract the momentum score for top narratives (e.g. ZK Compression, DePIN).
2. **Maps to Tokens:** Dynamically maps leading narratives to representative ecosystem tokens (e.g. ZK Compression → SOL, Firedancer → JTO).
3. **Applies Strategy:**
   - **NMS > 90**: Triggers a **BUY** signal. Agent initiates a DCA buy.
   - **NMS < 70**: Triggers a **REBALANCE** signal. Agent starts a rebalancing sell off.
   - Otherwise: **HOLD**.
4. **Leverages Jupiter APIs:**
   - **Jupiter Price API v2:** Fetches the real-time exact pricing for the selected tokens.
   - **Jupiter Tokens API:** Fetches on-chain token metadata.
   - **Jupiter Swap API v2:** Simulates the optimal routing and builds the quote payload for the intended trade without executing it on-chain (Simulation Mode).
5. **Generates Output:** Produces `data/strategy_output.json`, which directly powers the stunning Dashboard.

## How to Run It

1. Ensure you have Node.js installed.
2. Run the agent to generate the strategy output from signals:
   ```bash
   node agent/jupiterAgent.js
   ```
3. Open `index.html` in your browser to view the interactive Trading Signal Dashboard.
